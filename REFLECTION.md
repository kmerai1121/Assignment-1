# Reflection

## 1. Can I explain what my code does ?

- My code creates a personal resume webpage using HTML and semantic HTML elements. The webpage is basically divided in various sections such as - About Me, Skills, Experience, Education, Projects and Contact Information.

I used semantic elements such as <header>, <nav>, <main>, <section>, <article> to organize the webpage in a proper way and to improve its accessibility. The navigation links allow users to move between different sections of the page easily.

I also made a profile image with descriptive alt text, links to professional profiles, and an SVG graphic to overcome assignment requirements. Overall, all the parts of the code work together to create a clean and accessible online resume webpage.

## 2. What was my coding process ? 

I started by setting my project folder and initializing a Git Repository. After creating the basic HTML document structure, I gradually added sections one by one. 

At first, I made the header and navigation section. After that, I added the Contact Information -> About Me -> Skills -> Experience -> Education -> Projects.

After completing the webpage content, I reviewed the HTML structure carefully and used validation techniques to identify and fix errors. Finally, I improved accessibility by adding alt attributes and ARIA labels where needed.

## 3. What challenges did I have ? 

One challenge I faced was understanding how to properly structure the webpage using HTML elements. At first, I was unsure where to place certain sections and how to organize the content in an appropriate manner. 

Another challenge i faces was working with accessibility features such as - alt text. I also had some difficulty managing file paths for images and making sure links are working perfectly. I solved these problems by testing the webpage over and over again in the browser and carefully checking my code for mistakes.

## 4. What would I do differently now ?

If I was asked to start this project again, I would spend more time planning the structure of the webpage before writing the code. Creating a rough layout plan that can help me organize the section more efficiently. 

Additionally, I would improve the overall content by adding more projects and professional details to make the resume more complete and effective. I would also prepare the HTML structure in a way that makes adding CSS styling easier in future assignments.

Overall, This project helped me to better understand semantic HTML, accessibility of a webpage and importance of organized development practices.
